# Required Acceptance Scenarios

1. `از صبح چند خطای 500 داشتیم؟`
2. `کدام سرویس بیشترین timeout را داشته؟`
3. `از صبح چند کد ملی داشتیم که بابت یک تراکنش دوبار از حسابشان برداشت شده؟`

Acceptance requires autonomous index/field discovery, read-only guarded execution, a Persian final answer, inspectable technical evidence and no operator-provided Elasticsearch query syntax.
